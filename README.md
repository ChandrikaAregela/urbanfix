# UrbanFix 🚧

UrbanFix is a Smart Civic Issue Reporting System developed using Python and Flask. It enables citizens to report civic issues such as potholes, garbage overflow, drainage problems, water leakage, and broken streetlights with supporting images and location details.

---

## 🌟 Overview

UrbanFix bridges the gap between citizens and local authorities by providing a centralized platform for reporting and monitoring civic issues. Users can submit complaints, track their status, and view analytics through an interactive dashboard.

---

## ❗ Problem Statement

Urban areas frequently face issues such as:

- Garbage overflow
- Potholes and damaged roads
- Water leakage
- Broken streetlights
- Drainage problems

Citizens often lack an easy and transparent way to report these issues and monitor their resolution progress.

UrbanFix addresses this challenge by offering a user-friendly web application for reporting, tracking, and managing civic complaints.

---

## 🚀 Features

### Citizen Features

- 📝 Report civic issues with detailed descriptions
- 📸 Upload images as supporting evidence
- 📍 Submit issue location information
- 🔍 Search and filter reported complaints
- 📌 Track complaint status in real-time
- 📅 View complaint submission date and time

### Smart System Features

- 🔁 Duplicate issue detection
- 📈 Automatic report count increment for duplicate complaints
- 📊 Interactive analytics dashboard
- 📉 Visual statistics using charts and graphs
- 📱 Responsive design for desktop and mobile devices

### Complaint Status Tracking

- Pending
- In Progress
- Resolved

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ChandrikaAregela/UrbanFix.git
cd UrbanFix
```

### 2️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 3️⃣ Activate the Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

### 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 5️⃣ Run the Application

```bash
python app.py
```

### 6️⃣ Open in Browser

```text
http://127.0.0.1:5000
```
